# 내 노래

개인용 음악 플레이어. 서버가 필요 없는 정적 웹앱입니다.

## 특징

- **기기 음악 파일** (mp3, m4a, flac 등) — 브라우저에 저장되어 오프라인 재생
- **유튜브 링크** — 유튜브 공식 임베드 플레이어로 스트리밍
- **오디오 주소** — mp3 직링크 재생
- 셔플 / 반복(전체·한 곡) / 순서 변경 / 잠금화면 컨트롤
- PWA — 홈 화면에 추가하면 전체화면 앱처럼 실행

## 데이터 보관

노래 파일과 재생목록은 **브라우저의 IndexedDB에만** 저장됩니다.
서버나 저장소로 업로드되지 않습니다. 기기·브라우저마다 목록이 따로 관리됩니다.

## 로컬에서 실행

```bash
python -m http.server 5173
```

`http://localhost:5173` 으로 접속합니다.

같은 Wi-Fi의 휴대폰에서 접속하려면:

```bash
python -m http.server 5173 --bind 0.0.0.0
```

`http://<PC의 IP>:5173` 으로 접속합니다. (PC가 켜져 있어야 합니다)

## 알려진 제약

- 유튜브 곡은 **화면을 끄면 재생이 멈춥니다.** 유튜브 임베드 정책상 우회할 수 없습니다.
  화면을 꺼도 계속 들으려면 mp3 파일로 추가하세요.
- 업로더가 외부 재생을 막아둔 영상은 재생되지 않습니다.
- `file://` 로 직접 열면 재생목록이 별도로 저장되고 오프라인 기능이 동작하지 않습니다.
  반드시 `http://` 또는 `https://` 로 접속하세요.
